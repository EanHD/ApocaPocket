# Doors and Windows

## Overview

- Buck: rough frame set in wall opening
- Lintel: horizontal member over opening
  carries wall load above it
- Doors: hung on wooden or iron strap hinges
- Windows: simple shutters before glazing
- Proper fit reduces drafts and heat loss
- Latch and bar secure against intrusion
- Priority order: door first, windows second

## Lintel Sizing

- Wood lintel: depth 1 in per foot of span
  minimum; e.g., 3 ft span = 3 in deep
- Stone lintel: flat arch or thick slab
- Lintel must bear on wall 6 in each side
- Never omit lintel; wall load crushes frame
- Cracks above openings indicate failure
- Add temporary shoring before repair

## Making a Door

- Frame: two stiles (verticals), top and
  bottom rail, middle rail for strength
- Boards: shiplapped or tongue-and-groove
- Diagonal brace from hinge side down
- Fasten with wooden pegs or cut nails
- Test in opening before hanging; fit tight
  but not binding

## Hanging a Door

- Strap hinges: iron straps wrap stile
- Pintle: eye or pin set in frame
- Hinge must resist door weight
- Shim and level frame before fixing
- Three hinges for heavy doors
- Adjust by bending strap if needed

## Window Shutters

- Interior or exterior wooden shutters
- Simple board-and-batten construction
- Hung like doors on small strap hinges
- Latch with wooden turn button or bar
- Oiled cloth or scraped animal membrane
  for light-transmitting panel option
- Glazing when glass-making is available

## Latches and Bars

- Wooden latch: pivoting wooden bar
- String latch: pull string lifts latch
  from outside; lock by removing string
- Drop bar: heavy timber drops in brackets
  for security against forced entry
- Secure from inside: no string access
- Combine latch and bar for day/night use

## Long-Term Value

- All components made from local timber
- Simple tools: saw, chisel, mallet, plane
- Repairs easy with same materials
- Well-made door lasts 100+ years
- Security adds community safety value
