# Practical Math

## Overview

- Four operations: add, subtract, multiply,
  divide; all else builds from these
- Fraction and ratio: essential for mixing,
  building, and trade
- Area and volume: materials estimation
- Proportion: scaling recipes and plans
- No calculator needed; paper and pencil
- Mental math shortcuts worth learning
- Document formulas for community use

## Area Calculations

- Rectangle: length x width
- Triangle: base x height / 2
- Circle: 3.14 x radius x radius
- Irregular: divide into rectangles and
  triangles; add results together
- Use for: field size, roof area,
  floor area, wall area for materials

## Volume Calculations

- Box: length x width x height
- Cylinder: 3.14 x radius^2 x height
- Cone: 1/3 x base area x height
- Sphere: 4/3 x 3.14 x radius^3
- Use for: tank capacity, soil volume,
  grain storage, cistern sizing

## Ratios and Proportions

- Ratio: relationship between quantities
- 2:1 mix means 2 parts A per 1 part B
- Scale up: multiply all parts equally
- Cross-multiply to find unknown:
  if 3/4 = x/12 then x = 3x12/4 = 9
- Use for: mortar mixes, soil amendments,
  recipe scaling, chemical dilutions

## Fractions

- Add fractions: find common denominator
- 1/3 + 1/4 = 4/12 + 3/12 = 7/12
- Multiply fractions: multiply tops and
  bottoms separately: 2/3 x 3/4 = 6/12 = 1/2
- Divide: flip second fraction and multiply
- Convert to decimal: divide top by bottom
- Use fractions for precision; decimals
  for calculation

## Estimation Skills

- Round numbers for quick mental checks
- 10% of anything: move decimal left one
- Double-check big purchases by estimate
- If estimate and calculation differ much:
  recheck; likely an error somewhere
- Better to overestimate materials 10%
  than to underestimate and run short

## Long-Term Value

- Math is the language of all building
- Trade fairness requires shared calculation
- Survey, navigation, astronomy all need
  basic arithmetic and geometry
- Teach arithmetic before anything else
- Written math preserves community knowledge
