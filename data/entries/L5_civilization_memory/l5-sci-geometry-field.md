# Field Geometry

## Overview

- Geometry: measure and describe space
- Field use: layout buildings, roads,
  fields, canals accurately
- 3-4-5 triangle: simplest right angle tool
- Plumb bob: vertical reference
- Level: horizontal reference
- Batter boards and string lines for layout
- No instruments beyond cord and stakes

## The 3-4-5 Right Angle

- Any triangle with sides 3-4-5 has one
  90-degree angle (Pythagorean theorem)
- Scale: 6-8-10, 9-12-15, 12-16-20
- Use for: corner squares, setting posts,
  checking walls, laying out foundations
- Method: measure 3 ft on one line,
  4 ft on second; adjust until 5 ft
  between end points; angle is 90 degrees
- Verify by measuring both diagonals equal

## Batter Boards

- Set stakes 2 ft outside each corner
- String lines define the building edges
- Batter boards stay while foundation digs
- Lines reattached to same notch each time
- Check square before every pour or build
- Level strings with line level or water tube
- This method unchanged since Rome

## Level and Plumb

- Plumb bob: weight on string = vertical
- Spirit level: bubble in water; horizontal
- Water tube level: water seeks own level
  over any distance; very accurate
- A-frame level: two sticks, plumb bob
- Check walls with plumb; foundations level
- Both references critical for all building

## Area and Distance

- Rope knotted at equal intervals: measure
- Stadia: measure baseline; triangulate
- Pace count: calibrate personal pace
  (typically 2.5 ft per step for adult)
- Count paces for distance estimation
- Map small area: triangulate from baseline
- Record dimensions on scale drawing

## Angles Without

- Bisect angle: swing equal arcs from vertex
- Trisect 90 degrees: three 30-degree steps
- 60-degree angle: equilateral triangle
- Slope ratio: 4:12, 6:12, 12:12 (rise:run)
- All slopes expressible as ratios
- Clinometer: protractor with plumb bob
  for measuring slope angles

## Long-Term Value

- Accurate layout prevents costly mistakes
- 3-4-5 rule: ancient and universal
- No instruments needed beyond cord
- Basis for land surveying and boundaries
- Teach as early as age 8-10
