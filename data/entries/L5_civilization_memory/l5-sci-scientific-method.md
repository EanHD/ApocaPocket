# Scientific Method

## Overview

- Science: systematic way to build knowledge
- Method: observe, question, hypothesize,
  predict, test, record, repeat
- Distinguishes knowledge from belief
- Builds on previous work; cumulative
- Self-correcting: errors found by retesting
- Requires no equipment to apply
- Most valuable intellectual tool available

## Observation

- Record what you see; not what you expect
- Quantify: count, measure, time events
- Separate observation from interpretation
- Observation: "plant grew 2 in this week"
- Interpretation: "plant grows faster in sun"
- Record both but label them separately
- Consistent observation period matters

## Forming a Hypothesis

- Hypothesis: testable statement of cause
- Good: "If X, then Y will occur"
- Example: "More compost increases yield"
- Must be falsifiable: can be proven wrong
- Not a hypothesis: "This plant is angry"
- Not testable = not science
- One variable changed at a time

## Designing Tests

- Control: everything same except variable
- Test group: variable changed
- Control group: variable unchanged
- Compare results between groups
- Repeat 3+ times: single result unreliable
- Record everything including failures
- Negative results are valid results

## Recording Results

- Date every entry in field journal
- Include: conditions, measurements,
  observations, any deviations from plan
- Sketch diagrams when useful
- Do not edit past entries; add corrections
- Consistent format allows comparison
- Others must be able to repeat your work

## Drawing Conclusions

- Compare test vs control results
- Difference shows effect of variable
- Small or mixed results: need more tests
- Never claim more than data shows
- Honest uncertainty is scientific
- Share results; invite critique
- Revise hypothesis and retest if needed

## Long-Term Value

- Prevents quackery and false practice
- Separates effective from ineffective
- Builds reliable knowledge base
- Agriculture, medicine, and engineering
  all advance through this method
- Teach children; amplifies community IQ
