# Making Files and Rasps

## Overview

- File: rows of parallel chisel-cut teeth
- Rasp: individually punched raised teeth
- Material: high-carbon steel (1% carbon)
- Forge to shape; anneal; cut teeth;
  then harden and temper
- Files enable all precision metal work
- Without files: no flat surfaces, no fit
- Most critical secondary tool in shop

## Steel Preparation

- Start with high-carbon steel bar
- Forge to file blank: flat bar, tapered
- Width and thickness match desired file
- Tang: narrow end for handle fitting
- Anneal fully: heat to orange, cool in ash
- File surface must be dead soft for
  tooth cutting; anneal is critical

## File Tooth Cutting

- Secure blank on lead block or wood
- Chisel: thin, sharp, 70-80 degree angle
- Strike chisel with hammer; cut rows
- Each stroke: advance 1/32 to 1/16 in
- Rows must be uniform spacing and depth
- Cross-cut: second set at angle to first
- This creates double-cut teeth

## Rasp Tooth Cutting

- Single-tooth punch: flat-nosed chisel
- Strike individually to raise each tooth
- Random pattern preferred for smooth cut
- 6-10 teeth per square inch for coarse
- 20+ per square inch for medium rasp
- Angle punch slightly forward; tooth
  should point toward cutting direction

## Hardening

- Heat blank uniformly to critical temp
  (non-magnetic; dull cherry-orange)
- Quench in warm (120F) brine or oil
- Warm quench reduces cracking risk
- Air quench if steel is very high carbon
- Test hardness: file corner of blank
  should skate off, not bite

## Tempering Files

- Files used cold; temper at 350-400F
  (pale yellow color on polished steel)
- Any higher: teeth lose hardness
- Handle in wooden chuck for even heat
- Commercial oven or temper bath works
- Lead bath at 380F: precise and even
- After temper: quench in oil to freeze

## Long-Term Value

- Files are the foundation of precision work
- Enable all machine-less metalfitting
- A set of files transforms a shop
- Skills transferable to saw-making,
  gear-cutting, and measuring tools
- High value trade goods in any community
