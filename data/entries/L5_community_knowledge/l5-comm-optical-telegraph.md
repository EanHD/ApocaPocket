# Optical Telegraph

## Overview

- Optical telegraph: visual signals relay
  messages between hilltop stations
- Chappe system (France 1792): arm positions
  encode letters; relay across country
- Speed: Paris to Lille (150 miles) in minutes
- Range: 10-20 miles per station hop
- Components: tower, movable arms or shutters,
  codebook, telescope for reception
- Sustained operation needs trained operators

## Signal Mechanisms

- Chappe arms: large pivoting wooden arms
  on tall mast; positions encode codes
- Shutter telegraph: matrix of open/closed
  panels; binary encoding
- Polybius square: 5x5 grid; two signals
  give row and column for letter
- Simpler: flag semaphore from towers
  (see semaphore entry)
- Arm mechanism: visible at greater distance

## Chappe Arm System

- Regulator: horizontal main arm
- Indicators: two shorter arms at each end
- Each indicator has 7 angle positions
- Total: 7 x 7 = 49 combinations minimum
- Codebook maps combinations to words or
  letters; greatly increases throughput
- Message rate: 3 symbols per minute typical
- Codebook updates transmitted as needed

## Station Construction

- Tower: 20-40 ft for visibility above trees
- Wood frame construction; cross-braced
- Operator cabin: shelter for weather
- Mechanism at top: ropes or rods control
  arms from inside cabin
- Viewing platform or telescope mount
- Night operation: impossible without lights

## Codebook Design

- Number each common word and phrase
- Letters: for spelling uncommon words
- Operational codes: start, end, repeat,
  error, urgent, routine
- Security codes: enemy-contact signals
- Copies: operator + station commander
  + central archive; three minimum
- Update annually; old codes retired

## Operations

- Shift: two operators; one sends, one watches
- Log all messages in station journal:
  time, direction, content, forwarded time
- Unclear signal: repeat request code
- End of day: all-clear signal both directions
- Maintenance: oil mechanism joints weekly
- Test transmission: daily check signal

## Long-Term Value

- Message in minutes vs hours by runner
- Network is defensible infrastructure
- Roman Polybius system worked this way
- Rebuild as regional governance scales
- Pairs with runner relay for off-network
