# Improvised Blacksmith

## The Salvage Mindset

- Functional smithing needs fire, mass, hammer
- Professional tools ideal but not required
- Brake drum forge + railroad track anvil
  is a proven functional combination
- Hammer: any 1-2 kg steel hammer
- Tongs: vice grip pliers initially
- Start working, upgrade as you learn

## Brake Drum Forge

- Find automotive brake drum (any size)
- Set on legs (angle iron or pipe)
- Run 2.5cm pipe through bottom center
- Pipe = tuyere (air inlet)
- Connect to blower or bellows
- Fill with charcoal above tuyere
- Works immediately, lasts years

## Railroad Track Anvil

- Section of rail weighing 30+ kg
- Flat web section = anvil face
- End of rail = horn (for curves)
- Mount vertically in wood stump
- Bolt or chain to prevent tipping
- Hard steel: excellent for forging
- File will barely mark rail (correct)

## Other Anvil Options

- Any dense steel block over 20 kg works
- Large sledgehammer head (smaller)
- Chunk of I-beam set upright
- Solid steel shaft sections
- Heavier is better: mass absorbs energy
- Soft steel (re-bar) is a bad anvil

## Improvised Tongs

- Vice-grip locking pliers work for first tools
- Cannot hold irregularly shaped stock well
- Make proper tongs as first project
  (draw out, form jaws, rivet)
- Simple flat-jaw tongs: handles any flat stock
- Ring tongs: hold round stock securely

## Tool Priority Order

- 1. Forge (any heat source)
- 2. Anvil (any heavy steel)
- 3. Hammer (1-1.5 kg cross-peen)
- 4. Tongs (vice grips until forged ones done)
- 5. Quench bucket
- 6. Files for finishing
- Everything else is a bonus

## First Projects

- Forge a nail (teaches drawing out)
- Forge a hook (teaches bending)
- Make your own tongs (teaches most skills)
- Make a knife from a file (stock removal)
- Repair a cracked or broken tool
