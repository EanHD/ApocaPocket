# Trebuchet Mechanics

## Operating Principle

- Long arm on pivot: counterweight on short end
- Projectile sling on long end
- Counterweight falls, long arm rises
- Sling whips forward, releases at angle
- Gravity powers the system
- Highly accurate with consistent ammunition

## Component Ratio

- Long arm to short arm: 5:1 to 6:1
- Counterweight: 100x projectile weight
- For 1kg projectile: 100kg counterweight
- Range: 150-200m with proper tuning
- Accuracy: hit same 3m area repeatedly

## Frame Construction

- A-frame uprights, well-braced
- Pivot axle: iron pin through uprights
- Axle must support full system weight
- Sling: rope attached to end of long arm
- Sling length: equal to long arm length
- Release pin: adjustable angle sets range

## Adjusting Range

- Counterweight position: closer to pivot = less range
- Sling length: longer = more range, less accuracy
- Release angle: critical, changed with pin hole
- Tune in stages: add counterweight gradually
- Record settings for each range target
- Consistent ammunition critical for accuracy

## Other Applications

- Heavy construction material placement
- Moving stones, logs across difficult terrain
- Emergency lifting over obstacles
- Scale version for testing mechanisms
- Teaching mechanical principles

## Quick Build Estimates

- For 1kg projectile at 100m range:
  Long arm 3m, short arm 0.5m
  Counterweight 100-150 kg
  Frame height 2.5m
- For 5kg at 100m:
  Long arm 4m, counterweight 500kg
  Frame must be very robust

## Historical Context

- Muslim armies used at Crusader fortifications
- Chinese used c. 300 BC (simpler mangonel)
- Counterweight trebuchet: c. 1200 AD Europe
- Made city walls obsolete before gunpowder
