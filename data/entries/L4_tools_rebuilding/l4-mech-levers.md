# Lever Systems

## Basic Principle

- Lever: rigid bar rotating around pivot (fulcrum)
- Mechanical advantage = load arm / effort arm
- Load arm: distance from fulcrum to load
- Effort arm: distance from fulcrum to effort
- Long effort arm + short load arm = large MA
- Archimedes: "Give me a place to stand
  and I will move the Earth"

## Class 1 Lever

- Fulcrum between load and effort
- Examples: seesaw, crowbar, scissors
- Can have MA > 1 or < 1 depending on position
- Balance: equal moments on each side
- Most common lever for lifting
- Effort and load move in opposite directions

## Class 2 Lever

- Load between fulcrum and effort
- Examples: wheelbarrow, nutcracker, door
- Always MA > 1
- Effort always less than load
- Effort and load move same direction
- Wheelbarrow: fulcrum at wheel, load in bucket

## Class 3 Lever

- Effort between fulcrum and load
- Examples: tweezers, forearm, shovel
- Always MA < 1 (speed and range of motion)
- Load force greater than effort force
- Trades force for speed and range
- Biological example: most arm movements

## Calculating MA

- MA = effort arm length / load arm length
- Example: 2m bar, fulcrum 20cm from load
  MA = 180cm / 20cm = 9x
- 90kg rock: need only 10kg effort
- Longer bar: more advantage
- Find lever point that gives needed MA

## Improvising Levers

- Crowbar under stuck object with block as fulcrum
- Long log as lever for moving heavy stones
- Any rigid object works as lever
- Longer = more advantage (up to practical limit)
- Combined levers: double MA
- Capstan bar: lever rotating around shaft

## Limitations

- Must have solid fulcrum point
- Lever itself must not bend
- Longer levers flex: use stiffer material
- Distance moved by load is reduced
  inversely with MA
- High MA = short movement per stroke
