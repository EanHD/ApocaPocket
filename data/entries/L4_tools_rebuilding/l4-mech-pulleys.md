# Pulley Systems

## Single Fixed Pulley

- Changes direction of force only
- No mechanical advantage (MA = 1)
- Lifting 100kg requires 100kg force
- But can pull DOWN to lift UP (ergonomic)
- Attach to overhead anchor point
- Simplest block and tackle component

## Single Movable Pulley

- Pulley moves with the load
- Rope attaches to anchor, wraps pulley,
  goes up to effort point
- MA = 2 (two rope sections support load)
- Lift 100kg with 50kg effort
- Load moves half the distance pulled

## Compound Pulleys

- MA = number of rope sections on load
- 2 pulleys: MA = 2
- 3 pulleys: MA = 3
- 4 pulleys: MA = 4
- Each added pulley: pull more rope for movement
- "Block and tackle" = set of compound pulleys

## Quick MA Count

- Count ropes attached to moving block
- That number is your MA
- Friction reduces actual MA by 10-15%
- per pulley
- 4-pulley system: ~75% efficiency real-world
- Still 3x advantage for practical work

## Improvised Pulleys

- Wooden wheels with groove carved in edge
- Metal pin or bolt through frame as axle
- Wire bail holds to anchor point
- Or: rope loop around smooth post
  (capstan-style, low efficiency)
- True pulleys: rotate, reduce friction
- Static posts: more friction, lower MA

## Heavy Lift Rig

- Anchor upper block to strong fixed point
- Tie lower block to load
- Lead rope through blocks alternating
- Run free end to effort position
- Add ratchet or cleat: hold load without effort
- Test with small load before full weight

## Practical Applications

- Lifting logs, stones, equipment
- Raising heavy building components
- Pulling stuck vehicle or equipment
- Raising water from deep wells
- Moving large animals (veterinary)
- Loading cargo to elevated storage
