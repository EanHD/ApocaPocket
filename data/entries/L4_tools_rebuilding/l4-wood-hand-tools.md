# Hand Tool Woodworking

## Essential Hand Tools

- Saw: crosscut and rip (different tooth angles)
- Plane: smoothing and jointing
- Chisels: 6mm, 12mm, 25mm widths minimum
- Mallet: wood or leather, not metal hammer
- Marking gauge: scribing lines parallel to edge
- Square: checking 90 degree angles
- These 6 tools build most things needed

## Saw Technique

- Mark cut line with marking gauge or pencil
- Knife line is more accurate than pencil
- Start cut with pull stroke on waste side
- Three fingers guide blade on first stroke
- Keep saw at 45 degrees to surface
- Push and pull evenly, let teeth do work
- Keep saw plumb (not tilted sideways)

## Plane Technique

- Plane must be sharp (see sharpening entry)
- Set blade depth: just barely protrudes
- Hold with both hands: front knob, back handle
- Push with body weight, not just arms
- Work with grain direction (downhill of grain)
- Check for flat with straight edge often
- Thin curly shaving = correct depth

## Chisel Technique

- Always chisel with grain or across it
- Never against grain (tear-out)
- Bevel down for paring (fine work)
- Bevel up for chopping mortises
- Mallet: controlled, deliberate blows
- Never use chisel with palm pressure on blade

## Layout and Marking

- Marking knife: more accurate than pencil
- Mark all critical dimensions first
- Use square for all 90 degree references
- Work from reference face and edge always
- Label reference face and edge with mark
- All measurements from same reference

## Grain Direction Rules

- Read grain by looking down the face
- Grain slopes: plane uphill (into the slope)
- Going downhill: tear-out occurs
- End grain: harder to cut, plane obliquely
- Quarter-sawn wood: most stable, easiest
- Flat-sawn: more figure, more movement

## Tool Storage and Care

- Store planes on side (not on iron)
- Retract irons before storage
- Light coat of oil on metal prevents rust
- Hang chisels or store edge-up
- Sharp tools require less force: safer
