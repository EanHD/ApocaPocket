# How to Study

## Why This Matters
In survival scenarios, learning speed = competitive advantage. This entry covers techniques that maximize retention and skill acquisition.

## Memory Techniques

### Spaced Repetition
- Review at intervals: 1 day -> 3 days -> 7 days -> 30 days -> quarterly
- Boosts retention to 80-90% vs 20-30% without review; 5-10 min per session

### Chunking
- Working memory holds 7+/-2 items  -  break complex info into 3-7 labeled chunks
- Learn chunks individually, then combine once each is solid
- Example: Plant ID = "lobed leaves + acorns + rough bark" (3 chunks, not dozens of details)

### Memory Palace (Method of Loci)
- Pick a familiar route; place vivid mental images at 10-20 distinct locations
- Walk through mentally to recall; 2-3x better retention than rote memorization
- Example: front door = dandelion, kitchen = cattail, bedroom = acorns

### Active Recall
- Close the book and force yourself to remember  -  do NOT re-read passively
- Methods: flashcards - blank paper test (write everything, no peeking) - teach-back - self-quiz
- Aim for 70-85% correct on first try (too easy = no learning; too hard = frustration)

### Feynman Technique
1. Explain topic out loud as if teaching a beginner
2. Notice where you stumble  -  those are knowledge gaps
3. Study those gaps; simplify explanation using analogies
4. 15-30 min per concept; deepens understanding and exposes blind spots

## Practice Schedules

### Deliberate Practice
- Identify the specific weak skill; drill only that component in isolation
- Require immediate feedback (did it work?); repeat until automatic
- Example: fire-starting weak at tinder -> 20 reps of only tinder prep and spark catching

### The 20-Hour Rule
- ~20 focused hours = basic competency in any skill
- 30 min/day x 40 days - 1 hr/day x 20 days - 2 hrs/day x 10 days
- Requirements: focused (no distractions), structured (good method), feedback (know if correct)

### Flow State
- Too easy: boring, no learning - Too hard: anxiety, quit - Just right: flow
- If bored: add constraints or increase speed - If frustrated: break down further
- Signs of flow: lose track of time, fully absorbed, progress feels satisfying

## Study Environment
- Light: natural best; bright artificial otherwise (dim = drowsy)
- Noise: quiet or consistent white noise (intermittent noise breaks focus)
- Eliminate distractions: phone silent in another room; close unneeded tabs; set a timer
- **Pomodoro:** 25 min focus + 5 min break x 4 = 2 hrs of quality work

## Application Scenarios
**Plant ID:** chunk 1-2 key features per plant - active recall with photos - spaced repetition weekly
**Repair skills:** deliberate practice on the hardest step - 20-hour rule with real materials
**Memorizing procedures:** memory palace for data - chunk into logical sets - spaced repetition

## Quick Reference
```
EFFECTIVE STUDY CHECKLIST:
 Break into chunks (7+/-2 items)
 Active recall (quiz yourself)
 Spaced repetition (1-3-7-30 days)
 Practice weak points (deliberate practice)
 Match challenge to skill (flow state)
 Teach someone else (Feynman technique)
 Minimize distractions (Pomodoro)
 20 focused hours = basic competency

AVOID:
NO Passive re-reading
NO Highlighting without processing
NO Cramming the night before
NO Practicing only what you are good at
```
