# Dead Reckoning

## Why It Matters

- GPS fails: no signal, dead battery
- Map plus dead reckoning is reliable
- Keeps you on course in low-vis
- Allows position estimate without sight
- Military standard navigation method
- Error known and manageable

## Pace Count Basics

- 100 meters = roughly 65-70 paces
- 1 pace = 2 steps (left foot hits twice)
- Your pace changes with terrain
- Calibrate on known 100 m first
- Count left foot contacts only
- Use ranger beads or knotted cord

## Starting Out

- Note starting point on map
- Record bearing (compass degrees)
- Begin pace count from zero
- Mark paces every 100 meters
- Update position on map each mark
- Note major terrain features passed

## Adjusting for Terrain

- Uphill: paces are shorter
- Downhill: paces are longer
- Brush and brush: add 15% to count
- Night: add 20% to count
- Calibrate terrain factor first
- Use terrain features to verify

## Error Correction

- At each landmark: reset if confirmed
- If terrain does not match map: stop
- Back-track to last confirmed point
- Do not compound errors by guessing
- Better slow and sure than fast lost
- Mark each checkpoint on map

## What Can Go Wrong

- Bearing drift from not checking compass
- Pace count lost in obstacle crossing
- Terrain estimation too optimistic
- Map scale misread early

## Practice Benchmark

- Goal: Navigate 1 km on bearing
  within 50 m of target
- Sign of mastery: 3 km route with
  less than 100 m total error
