# Hand Line Fishing

## Overview

- No rod needed -- just line and hook
- Most efficient gear-to-calorie ratio
- Set multiple lines for passive fishing
- Paracord core strands or natural fiber
  both work as line

## Line Materials

- Paracord inner strands: best option
- Plant fiber twisted to line: OK
- Braided grass or bark fiber: works
- Fishing line if available: ideal
- 15-20 ft length for most situations

## Basic Setup

- Tie hook to end of line
- Add weight 6-8 in above hook:
  small stone or metal nut
- Bobber optional: stick float tied
  2-3x depth of water above hook
- Wrap extra line on stick or forked
  branch for casting/storage

## Casting and Retrieve

- Swing hook in circle overhead
- Release at 45-degree angle forward
- Allow to sink to desired depth
- Retrieve slowly with hand-over-hand
- Feel for light taps -- set hook fast

## Passive Set Lines

- Tie line to branch overhanging water
- Bait hook, set at desired depth
- Check every 30-60 minutes
- Set 3-5 lines for best yield
- Mark with torn cloth so you find them

## Knots to Know

- Improved clinch: hook to line
- Square knot: line to line
- Bowline: secure anchor knot
- Wrap end 5-6x around line,
  pull through loop, cinch tight
